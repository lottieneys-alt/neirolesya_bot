# 📢 NotificationBot

Telegram-бот для рассылки сообщений, фото и видео по расписанию.  
Поддерживает панель администратора, добавление и редактирование сообщений, а также управление расписанием через команды.

---

## 🚀 Функции
- 👤 Подписка и отписка пользователей
- 👑 Панель администратора
- 📝 Добавление, изменение и удаление сообщений
- ⏰ Настройка времени отправки сообщений
- 🖼️ Отправка фото и видео по расписанию
- 📊 Статистика
